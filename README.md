# 🌍 Terra Blockchain Project — Bonus DApp with Node.js

This bonus project connects to the **Terra blockchain** using **Node.js** to demonstrate core concepts of smart contract interaction, wallet management, token operations, and blockchain integration.

---

## 🧩 Project Overview

This Node.js-based project teaches you how to:

- Connect to a Terra testnet node
- Create and fund (airdrop) a Terra wallet
- Read on-chain data
- Transfer and swap native tokens (UST, LUNA)

---

## 📚 Included Lessons (from course)

- ✅ About this bonus project
- ✅ Connect to a Terra node
- ✅ Create and airdrop to a Terra account
- 🔄 Read data from the Terra blockchain
- 🔄 Transfer and swap UST/LUNA
